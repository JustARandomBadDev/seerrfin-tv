# Security policy

The project is pre-release. No stable version is currently supported.

Please **do not** disclose real Jellyfin access tokens, Seerr API keys, passwords, server addresses or private library data in public issues.

If GitHub private vulnerability reporting is enabled, use that channel for security-sensitive reports. Otherwise, contact the repository maintainer privately via their GitHub profile rather than publishing exploit details.

The app must not embed a privileged Seerr API key. Security-sensitive design changes require review before release.
