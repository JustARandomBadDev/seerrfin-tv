# Contributing

Seerrfin TV is currently at the bootstrap stage. Please open an issue to discuss significant changes before implementing them.

## Development conventions

- Follow `AGENTS.md` and `docs/architecture.md`.
- Keep pull requests focused on one task.
- Use conventional commit subjects without scopes (`feat: ...`, `fix: ...`).
- Include a reproducible test, commands actually run, and any TV device validation.
- Do not paste Jellyfin / Seerr credentials, real server URLs or personal library screenshots.
- Document compatibility assumptions, especially for player codecs and Seerr authorization.

## Pull requests

Use the included pull request template. CI will be introduced after the Gradle Android TV bootstrap is verified.
