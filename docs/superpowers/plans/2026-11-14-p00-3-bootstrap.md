# P00.3 Android TV Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:executing-plans` to implement this plan task-by-task.

**Goal:** Produce a minimal, reproducible Android TV app whose D-pad focus and
activation behavior are verified on the authorized physical TV.

**Architecture:** One `app` module using AGP built-in Kotlin and Compose for
TV. A tiny immutable bootstrap state supports activation feedback; the screen
uses three focusable TV buttons and explicit initial focus.

**Tech Stack:** AGP 9.3.3, Gradle 9.5.0, JDK 17, API 37/36/26, Compose BOM
2026.09.00, Compose for TV 1.1.0.

**Spec:** `docs/architecture.md`, `docs/decisions.md`, and the P00.3 request.

## Global constraints

- Namespace/application ID: `io.github.justarandombaddev.seerrfintv`.
- One `app` module; no Jellyfin, Seerr, Media3, storage, or future features.
- Use built-in Kotlin; do not apply `org.jetbrains.kotlin.android`.
- No commits, pushes, unrelated TV changes, or private server access.
- All ADB commands after discovery use one explicit serial.

## Review focus

- JDK 17 is the JVM actually running Gradle.
- The launcher intent and no-touch feature make the APK a TV application.
- Initial focus is visible and every action remains reachable by D-pad.
- Activation produces visible feedback without navigating to future features.
- Back exits cleanly without a crash.

### Task 1: Build scaffold and wrapper

**Files:** Gradle settings, version catalog, wrapper, app build file,
manifest, resources, and `.gitignore`.

- Verify API 37 and Build Tools 36.1.0 inputs.
- Create the single-module configuration with the accepted versions.
- Generate the Gradle 9.5.0 wrapper and prove it runs on JDK 17.

### Task 2: Bootstrap behavior using RED/GREEN

**Files:** `BootstrapStateTest.kt`, then `BootstrapState.kt`.

- Write a unit test proving an action activation changes the visible status.
- Run it before production code and observe the expected compilation failure.
- Implement the minimal immutable state and run the test green.

### Task 3: Compose for TV screen

**Files:** `MainActivity.kt`, `BootstrapScreen.kt`, `Theme.kt`, resources.

- Render title, bootstrap text, three TV buttons, and activation status.
- Request focus on the first action and expose an unmistakable focus border.
- Build, inspect the merged manifest, and verify ignored/generated files.

### Task 4: Physical TV validation

- Discover authorized transports and select exactly one.
- Install and launch only this debug APK.
- Verify foreground/process/crash state.
- Exercise D-pad, activation, and Back; use screenshots for visual evidence.

### Task 5: Documentation and final verification

- Update progress/setup only from observed results.
- Run unit tests and `assembleDebug` once more only if a correction required it.
- Confirm no secret/generated output is tracked and stop after P00.3.
